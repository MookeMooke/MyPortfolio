# Versions

The version is shown in the app's top-left corner and window title, and in the download's file name.
To release a new one: raise `version` in `package.json` (the first number is the V number) and add a line here.

- **V7**: Version shown in the app and file name. Warns if another copy is already open. Never reuses cached files from an older version.
- **V6**: Brick equalizer runs left to right, one bar per brick row. Only lit bricks show.
- **V5**: Music starts by itself and shows its status in the top bar.
- **V4**: Brick equalizer takes a measured wall area and brick size.
- **V3**: Brick equalizer preset. Fast-starting zip build.
- **V2**: Phone remote.
- **V1**: Desktop app: mapping, masks, media, effects, scenes, laptop sound.
